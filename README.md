# Hi, I'm Prijith Melvin 👋

**Embedded Firmware Engineer** · MCU drivers · Automotive bootloaders & UDS · Bengaluru, India

3+ years writing low-level Embedded C firmware for automotive microcontrollers: peripheral drivers and UDS bootloaders with dual-stage boot and dual-slot firmware rollback. Customer deliveries include Mahindra (in production in the Blazo truck), ZF Rane and Amara Raja Batteries.

- **Platforms:** NXP S32K144 / S32K344 · TI C2000 (incl. TMS320F28379D) · Infineon · Renesas
